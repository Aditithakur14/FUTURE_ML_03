# Ticket Booking Customer Support Chatbot

This project is an AI-powered customer support chatbot designed for movie and event ticket booking platforms.

## Features
- Friendly greeting and user interaction
- Answers common FAQs related to movie and event ticket booking
- Supports booking status, cancellations, refunds, and payment queries
- Smart fallback response for unrecognized questions
- Designed similar to real-world chatbots used by platforms like Amazon and Zomato

## Purpose
This chatbot was created as part of an internship task to demonstrate understanding of how AI-powered customer support chatbots work, including intent-based responses and conversation design.

## Scope
The chatbot is limited to:
- 🎬 Movie ticket bookings
- 🎉 Event ticket bookings
